# AutonoML

A multi-agent AI system for autonomous machine learning workflows.

## Overview

AutonoML orchestrates a pipeline of specialised agents — planner, research, execution, and evaluation — to handle complex ML tasks end-to-end.

## Stack

- **LLM**: Ollama (`llama3.2:3b`)
- **Embeddings**: `BAAI/bge-large-en-v1.5` via HuggingFace
- **Vector Store**: ChromaDB
- **Backend**: FastAPI
- **Frontend**: Streamlit
